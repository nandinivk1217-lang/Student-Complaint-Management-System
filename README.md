About the Project

The Student Registration System is a simple web-based application developed 
using Python and Flask. It allows students to enter their registration details 
through a user-friendly web interface.
This project was developed to understand Flask fundamentals, backend development, 
form handling, and connecting frontend pages with Python.

Features

Student registration form
Collects student details
Form validation
Success page after registration
Simple and user-friendly interface

Technologies Used

Python
Flask
HTML
CSS
